# Láska na cestách ♥

Hra pro Káťu: mapa Evropy s místy, kde jsme byli spolu, a minihrami (česky i ukrajinsky).

Celá hra je v jediném souboru `index.html`: fotky, fyzika i všechny hry jsou uvnitř. Nic dalšího není potřeba.

## Jak ji dát na GitHub Pages

1. Na github.com vytvoř nový repozitář, například `laska-na-cestach` (Public).
2. Klikni na **Add file → Upload files** a přetáhni sem `index.html` a `.nojekyll` (soubor `.nojekyll` může být skrytý, není nutný).
3. Dej **Commit changes**.
4. Otevři **Settings → Pages**. U „Source“ vyber **Deploy from a branch**, větev **main** a složku **/ (root)**, ulož.
5. Za minutu až dvě bude hra na adrese `https://TVOJE-JMENO.github.io/laska-na-cestach/`.

Pozor: stránky na GitHub Pages jsou veřejné. Kdo zná adresu, uvidí i vaše fotky. Stránka má značku `noindex`, takže by se neměla objevit ve vyhledávačích.
